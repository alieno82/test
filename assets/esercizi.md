# Esercizi JavaScript/TypeScript

## Esercizio 1: Esempi di oggetti

Crea esempi pratici per i tipi di oggetto più importanti contenuti in `basic-objects.js`. Ogni esempio dovrebbe includere:

- Inizializzazione dell'oggetto
- Uso pratico (es. aggiunta di elementi, chiamata di metodi)
- Stampa del risultato nel terminale

Tipi di oggetto da coprire:

- Object
- Array
- Function
- Date
- RegExp
- Map
- Set
- Promise

---

## Esercizio 2: Versione TypeScript di `basic-types`

Crea una versione TypeScript del file `basic-types.js`. Il file dovrebbe:

- Definire i tipi di dato in modo esplicito
- Includere annotazioni di tipo per tutte le variabili e funzioni
- Aggiungere interfacce o tipi personalizzati dove necessario
- Testare il file con Bun

---

  - Se necessario, cancella i test fatti per pulire l'ambiente.
